# 架构决策记录（ADR）

## ADR-001 规划器采用规则模板而非 LLM ReAct 循环

**状态**：已采纳　**日期**：2026-10-17

**背景**：Agent 规划有两种主流做法——LLM ReAct 循环（每步让模型决定下一个工具）与规则模板（意图分类 → 固定步骤 DAG）。

**决策**：默认规则模板。理由：
1. 目标用户场景是**无人值守**的内容运营巡检：LLM 故障/超时/幻觉不能让任务失败；
2. 步骤依赖关系需要**可解释**：运营要知道"为什么先查知识库再拉数据"，模板的 reason 字段天然携带；
3. 确定性让 18 个评测场景 100% 可复算，LLM 规划的评测方差会吞掉回归信号。

**代价**：意图覆盖受模板限制。缓解：探索兜底计划保证任何目标都有合理路径；`config.py` 预留 `PLAN_MODE` 与 `LLM_*`，接入 LLM 后走 auto（LLM 优先、失败降级）。

## ADR-002 违禁词护栏做意图感知

**状态**：已采纳　**日期**：2026-10-17

**背景**：初版输入护栏无差别拦截含违禁词的目标，导致「帮我审查这条文案：最佳选择」这种**合规体检请求**被自己人拦下（医生被疫苗误伤）。

**决策**：`REVIEW_INTENT` 关键词命中时，目标中的违禁词视为送检对象，任务级护栏放行，由合规工具给出 P0/P1 判定；输出层的违禁词打码保留（防止违禁词随结论二次传播）。

**教训**：护栏不是越严越好——**误拦截会让用户关掉护栏**，那才是最大的安全损失。

## ADR-003 轨迹格式 JSONL 而非单个 JSON

**状态**：已采纳　**日期**：2026-10-17

**理由**：
1. 事件**边产生边落盘**，进程崩溃保留部分轨迹（巡检场景的关键要求）；
2. grep / jq / pandas 直接读，接观测系统零成本；
3. seq 连续性校验让丢行可发现——审计可信度的底线；
4. 脱敏在写盘前完成，敏感串（API Key 等）绝不落磁盘。

**代价**：读回需要全文件扫描。轨迹都是小文件（<100 行），不构成问题。

## ADR-004 写操作：单一写工具 + 显式授权白名单

**状态**：已采纳　**日期**：2026-10-17

**决策**：全系统只有 `register_publish` 一个 side_effect 工具；默认挂起（blocked 而非报错），授权走 `CONTENTPILOT_APPROVED_WRITE_TOOLS` 显式白名单；写行为追加 JSONL 台账。

**为什么 blocked 而不是抛错**：写操作被拦是**预期行为**而非异常。状态机里它是 `blocked`，综合器会向用户解释「未获授权、如何授权」——护栏的输出要能教育用户，而不只是拒绝。

## ADR-005 评测断言全部确定性，不用 LLM-as-judge

**状态**：已采纳　**日期**：2026-10-17

**理由**：LLM-as-judge 引入的方差会让"这次 94% 下次 89%"成为噪音，回归信号被淹没。本项目评测断言全部可复算：状态、工具调用链、答案关键词包含/排除、轨迹完整性、预算约束。

**代价**：无法评估"答案写得好不好"。当前阶段评估的是**行为正确性**而非文采，这与工程目标一致。
